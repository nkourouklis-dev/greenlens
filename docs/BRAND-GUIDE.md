# GreenLens — Brand Guide

## 1. Concept: "Lens + Tag"
Ο φακός (κύκλος + χερούλι) αντιπροσωπεύει τη σάρωση/OCR — την πράξη του "κοιτάζω πιο προσεκτικά".
Μέσα στον φακό βρίσκεται μια μικρή ετικέτα προϊόντος με 3 γραμμές κειμένου — αυτό που το app κυριολεκτικά σαρώνει και διαβάζει. Δεν χρειάζεται μεταφορά (φύλλο/φύση) για να δηλωθεί το "υγεία" — αυτό το κουβαλάει ήδη το χρώμα (emerald) και το wordmark· το mark δείχνει με ακρίβεια *τι κάνει* το προϊόν: διαβάζει ετικέτες.
Η ελαφριά κλίση της ετικέτας (-15°) δίνει μια αίσθηση κίνησης/δυναμισμού μέσα στον στατικό κύκλο, χωρίς να ανταγωνίζεται το χερούλι.

Σκόπιμα αποφύγαμε: κόκκινο σταυρό, στηθοσκόπιο, φύλλο/φυτικά μοτίβα (δεν σαρώνουμε φυτά), ή οποιοδήποτε "ιατρικό" εικονογραφικό στοιχείο.

*(Προγενέστερη εκδοχή δοκίμασε "Lens + Leaf" — αντικαταστάθηκε γιατί δεν διάβαζε καθαρά σε μικρό μέγεθος και η μεταφορά "φύλλο" δεν ταίριαζε λογικά με τη βασική λειτουργία σάρωσης ετικετών.)*

## 2. Χρωματική παλέτα (tokens)
| Token | Hex | Χρήση |
|---|---|---|
| `--color-primary` | `#10B981` | Κύριο brand color — CTAs, δακτύλιος φακού, accents |
| `--color-primary-strong` | `#059669` | Hover/pressed states, βαθύτερος τόνος του primary |
| `--color-dark` | `#0F172A` | Φόντα, κείμενο σε light bg, dark-mode surfaces |
| `--color-light` | `#FFFFFF` | Φόντα σε light mode, κείμενο σε dark bg |
| `--color-neutral` | `#64748B` | Δευτερεύον κείμενο, captions, borders |

## 3. Τυπογραφία (πρόταση)
- **Display / Headlines:** Space Grotesk (700) — γεωμετρικό, τεχνολογικό, καλή αναγνωσιμότητα σε τίτλους.
- **Body / UI:** Inter (400/500/600) — εξαιρετική αναγνωσιμότητα σε μικρά μεγέθη, mobile-first, μεγάλη κάλυψη ελληνικών χαρακτήρων (greek subset).
- Το wordmark χρησιμοποιεί το ίδιο display font με letter-spacing -0.5 για συμπαγή, σύγχρονη αίσθηση.

## 4. Πότε χρησιμοποιείς κάθε παραλλαγή του λογότυπου

| Αρχείο | Πότε το χρησιμοποιείς |
|---|---|
| `logo-mark-primary.svg` | Προεπιλογή. Icon-only, πάνω σε λευκό/ανοιχτό φόντο (`#FFFFFF` ή ανοιχτά greys). Δακτύλιος `#10B981`, φύλλο `#0F172A`. |
| `logo-lockup-light.svg` | Header, navbar, footer πάνω σε ανοιχτό φόντο. Icon + wordmark μαζί. |
| `logo-mark-dark-bg.svg` / `logo-lockup-dark.svg` | Πάνω σε `#0F172A` ή οποιοδήποτε σκούρο φόντο (dark mode, hero sections, splash screen). Δακτύλιος παραμένει `#10B981` (το πράσινο "ζωντανεύει" πάνω σε σκούρο), το φύλλο γίνεται λευκό για αντίθεση. |
| `logo-mark-monochrome.svg` | 1-χρωματικές εφαρμογές: εκτύπωση σε ένα χρώμα, engraving, watermark, favicon σε system tray, μέρη όπου το brand color δεν είναι διαθέσιμο. Χρησιμοποιεί `currentColor` — βάλε το χρώμα μέσω CSS (`color: #0F172A` ή `color: #FFFFFF`). Η λεπτομέρεια του "φλεβίου" αφαιρείται εδώ για ευκρίνεια σε μικρό μέγεθος. |
| `app-icon-maskable-512.svg` | Πηγή για τα PWA/OS icons (Android adaptive icons, iOS). Έχει συμπαγές φόντο `#0F172A` και το mark μέσα στη "safe zone" ώστε να μην κόβεται όταν το OS εφαρμόζει mask (κύκλος/τετράγωνο/squircle). |
| `favicon.svg` (`/public/favicon.svg`) | Απλοποιημένη εκδοχή με παχύτερες γραμμές, χωρίς τη λεπτομέρεια του φλεβίου, για ευκρίνεια στα 16–32px του browser tab. |

**Κανόνας ελάχιστου μεγέθους:** το πλήρες lockup (icon + wordmark) να μη χρησιμοποιείται κάτω από 24px ύψος. Κάτω από αυτό, χρησιμοποίησε μόνο το icon mark.

**Clear space:** άφησε γύρω από το mark, σε όλες τις πλευρές, ελεύθερο χώρο τουλάχιστον ίσο με το πάχος του δακτυλίου του φακού (5.5 units στο πρωτότυπο grid των 64×64).

**Μην:** αλλάζεις την αναλογία δακτυλίου/χερουλιού/φύλλου, μην προσθέτεις shadow/gradient/3D εφέ στο mark — μένει επίπεδο (flat), όπως ταιριάζει στο "όχι ιατρικό, σύγχρονο startup" aesthetic.

## 5. Raster exports (ήδη έτοιμα στο kit)
Τα PNG icons και το OG image έχουν ήδη παραχθεί από τα SVG sources και βρίσκονται στο `/public`:

| Αρχείο | Πηγή | Μέγεθος |
|---|---|---|
| `public/icons/favicon-32.png` | `public/favicon.svg` | 32×32 |
| `public/icons/favicon-192.png` | `brand/app-icon-maskable-512.svg` | 192×192 |
| `public/icons/favicon-512.png` | `brand/app-icon-maskable-512.svg` | 512×512 (χρησιμοποιείται και για `purpose: maskable` στο manifest) |
| `public/icons/apple-touch-icon.png` | `brand/app-icon-maskable-512.svg` | 180×180, χωρίς διαφάνεια |
| `public/og/og-image.png` | HTML template (`brand/` lockup + tagline) | 1200×630 |

Αν αλλάξεις το mark στο μέλλον, ξανά-παρήγαγε αυτά τα PNG από τα ενημερωμένα SVG (π.χ. με sharp/Figma/Inkscape) — μην τα επεξεργάζεσαι απευθείας ως raster.
